# SIH-HACKATHON

A safety-focused route and travel application built with Expo, React Native, and TypeScript.

## Repository layout

- `frontend/` - complete Expo application
- `database/` - SQL migration files
- `docs/` - architecture, algorithm, and jury-preparation notes

## Run the frontend

```bash
cd frontend
npm install
npm run dev
```

For web:

```bash
npm run dev:web
```

## Notes

Keep secrets out of GitHub. Use environment variables and update `.gitignore` when needed.
